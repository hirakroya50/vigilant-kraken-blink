## Implementation sequence

1. Replace unsafe role scaffolding with independent bounded discovery, candidate/branch leases, heartbeat cancellation, collision fallback and structured logs.
2. Wire real Fitter drafting/review publication, acknowledged local Dyad Developer/Fixer sessions, protected Tester results, and reviewed read-only AI Triager evidence. No worker may manufacture a test success or approve its own Fit.
3. Validate exact-head lineage and protected diffs at publication; preserve fresh-testing requirements on new candidates. Add exact protected-test title coverage for Fit assertions.
4. Add read-only protected-main inspection and explicit-consented native GitHub merge-queue enrollment; never bypass protection or invent a custom merge algorithm.
5. Exercise offline safety and scheduling tests plus full strict production compilation; document actual results separately from live SOW cases.
6. On the trusted Mac, review/commit the control, prepare the pinned image, run actual independent role sessions and capture durable evidence for cases 1–13, 21, 22. These are external acceptance gates, not replaced by offline fixtures.

Automatic authorized candidate synchronization, authenticated event dispatch, trusted merge-group/main execution and committed npm lockfile migration remain outside this bounded implementation and are recorded as unresolved, not completed.
